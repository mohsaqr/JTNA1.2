## WIP_CoOccurrence/

The original co-occurrence scaffolding — `CoOccurrenceTNA`, `GroupCoOccurrenceTNA`,
`OneHotTNA`, and `SNA` analyses (R `.b.R`/`.h.R` + jamovi `.a/.u/.r.yaml`).

**Superseded by the top-level `CNA/` module** (package `CNA`, "Co-occurrence
Network Analysis"), which replaced these with the four dedicated data-type
analyses `CNAEventSingle`, `CNAEventCluster`, `CNABinarySingle`,
`CNABinaryCluster` plus shared `cna_utils.R` (see the 2026-03-02 entries in
`../CHANGES.md`).

Retained only in case the `SNA` / `OneHot` scaffolding is wanted again. Do not
develop here — work in `CNA/`.
